# PRODIGY_WD_02
A simple and responsive Stopwatch web application built using HTML, CSS, and JavaScript that allows users to start, pause, lap and reset time accurately.
A fully functional and responsive Stopwatch Web Application built using HTML, CSS, and JavaScript. This project includes Start, Pause, Reset, and Lap functionality, allowing users to track and record multiple lap times accurately.

🌟 Features

▶️ Start the stopwatch

⏸️ Pause the stopwatch

🔄 Reset the stopwatch

🏁 Record Lap times

📋 Display lap history dynamically

⏱️ Accurate time tracking (Hours : Minutes : Seconds : Milliseconds)

📱 Fully responsive design (Mobile & Desktop)

🎨 Clean and modern user interface
